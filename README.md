# Hackathon 2026: Build your own decoder

Additional info will become available on November 13, 2026 at 12:00 (CET).

## Installation

Requires Python 3.10 or newer. Choose whichever tool you feel most comfortable with.

**uv**

```bash
uv sync
```

**pip** (inside a virtual environment)

```bash
pip install -e .
```

**conda**

```bash
conda create -n hackathon python=3.12
conda activate hackathon
pip install -e .
```
